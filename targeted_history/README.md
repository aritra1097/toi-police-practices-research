# Targeted historical TOI research

Start with [findings and limitations](FINDINGS.md).

- [Evidence table](evidence_table.csv): reviewed reported patterns, near matches and exclusions, with sources.
- [Ordinary-crime gun-taking reports](ordinary_crime_gun_reports.csv): selected historical examples, retaining individual/group and fatal/nonfatal distinctions.
- [Headline catalogue](headline_catalogue.csv): search/filter the targeted historical candidate headlines; these are not incident counts.
- [Article index](article_index.csv): actual recovered titles, publication dates, retrieval status and review depth.
- [Collection audit](COLLECTION_AUDIT.md), [coding definitions](event_table_codebook.md) and [original headline-scan method](SCAN_README.md).

This is AI-assisted, purposive discovery. Police accounts remain attributed claims. Missing sources and unread/unscreened news do not establish historical absence. The recent four-state causal comparison is a separate exploratory analysis.

All selected source bodies and raw responses remain local. To repeat acquisition, use the published extended_queue.json with collect_targeted.py. Original headline scanning requires separately obtained input files matching the recorded hashes. The published CSVs preserve their source bytes, including ordinary CSV line terminators, so their input hashes remain verifiable.
