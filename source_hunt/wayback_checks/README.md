# Wayback feasibility check

Checked 27 October 2026 (New York date). Wayback is a possible recovery source, but a live page is not guaranteed to have a saved, complete snapshot. See the Internet Archive's [official guidance](https://archivesupport.zendesk.com/hc/en-us/articles/360004651732-Using-The-Wayback-Machine).

## Positive controls

The availability API reported saved successful copies of TOI's homepage, archive landing page and January 2003 monthly calendar. The [monthly calendar snapshot](https://web.archive.org/web/20231004143301/https://timesofindia.indiatimes.com/archive/year-2003,month-1.cms), captured on 4 October 2023, was actually downloaded and parsed successfully. It has the January 2003 calendar title and the same serial-day origin (30 December 1899). The calendar's day links are generated by JavaScript, rather than present as ordinary static links. The content date January 2003 is distinct from the capture date October 2023.

## Daily-list checks

The availability API returned no available snapshot for five daily URL variants spanning 2 January 2003, 1 January 2024 and 8 July 2026. The historical HTTP short-form 2003 URL was also checked with a 2023 reference timestamp and returned no snapshot. Two exact-URL CDX capture-index queries for the 2003 dated and short routes returned empty successful-response lists.

These are bounded negative search results, not proof the pages were never archived. A broader prefix search for other `/archivelist/` URLs timed out, so it remains unresolved whether other daily pages can be recovered at scale. We have not obtained an archived daily headline listing from these checks and do not count missing captures as zero-news dates.

The public JSON files preserve the exact requests and responses. Downloaded HTML stays local. No Save Page Now request was made; saving the current empty listing would not reconstruct an earlier populated version.
